## 6. Notas / Observacoes
- **Segurança (CA1)**: o RPC `ListUpcomingMatches` é protegido — garantir que **não** entra em `providePublicMethods`. A asserção ponta-a-ponta (sem token → `Unauthenticated`) vive no E2E (T7); aqui a invariante é estrutural (não adicionar à allowlist).
- **Acoplamento ao `clock.Clock`** (SCOPE §5): `clock.New` é provido por `auth.Module`; `match` consome do escopo raiz. Trade-off aceito (leve dependência implícita de ordem de módulos no `fx.New`).
- **Reuso da montagem**: `internal/server` é compartilhado por produção e E2E — não duplicar a cadeia de interceptors no teste.
- `export_test.go` só se o smoke test precisar de binds não-exportados; caso contrário, omitir (YAGNI).
