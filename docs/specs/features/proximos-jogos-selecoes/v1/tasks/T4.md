## 6. Notas / Observacoes
- **Determinismo (CA7)**: o teste-chave captura o argumento `cutoff` passado ao mock do repository e compara com `clk.Now()` do relógio fixo — prova que o corte vem do clock injetado, não do banco. Mover o relógio muda o conjunto (companion de integração em T3/E2E reforça).
- Anti-mock-driven-confidence (rule testing.md): para todo teste com mock, exista companion de integração sem mock cobrindo o mesmo caminho real — o caminho real com dados vive em T3 (repository).
- Sem sentinela nova: o domínio não tem "not found" (é listagem); lista vazia é sucesso.
