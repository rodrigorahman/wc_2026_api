## 2. Objetivo da Task
Criar a tabela `matches` (calendário da Copa: instante de início UTC, mandante e visitante, estádio, cidade, fase — sem placar/status) com integridade garantida por schema, escrever a query parametrizada que devolve os jogos futuros das favoritas de um usuário (filtro + dedup + ordenação numa única query) e regenerar o código tipado do sqlc. A query depende da coluna `code` (T1) para selecionar `home.code`/`away.code`.

## 6. Notas / Observacoes
- **Dedup estrutural**: o filtro é sobre a **linha da partida** (não há join multiplicador com a tabela de favoritas) — um jogo com duas favoritas aparece uma única vez. Validar em T3 (repository).
- **Corte determinístico**: `sqlc.arg(cutoff)` recebe `clock.Now()` do service; nunca `CURRENT_TIMESTAMP`.
- `kickoff` é instante UTC, mapeado via override `TIMESTAMP → time.Time` (mesma convenção de `created_at`).
- O código gerado pelo sqlc **não se edita à mão** (será sobrescrito). O campo `Code` que aparece em `NationalTeam` é inócuo ao domínio `nationalteam`.
