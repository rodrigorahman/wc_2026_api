## 2. Objetivo da Task
Adicionar a coluna `code` (sigla FIFA de 3 letras, ex.: `BRA`, `MEX`) à tabela `national_teams`, com backfill das 16 seleções já semeadas (migração 000002), espelhando o precedente de `flag_url` (migração 000005). A coluna é consumida exclusivamente pela query de partidas (T2/T3) — nenhuma alteração no código do domínio `nationalteam`.

## 6. Notas / Observacoes
- Espelha 000005 (`flag_url`): mesma técnica de `ADD COLUMN NOT NULL DEFAULT ''` seguida de UPDATE por id. `DROP COLUMN` é suportado pelo driver modernc (exercitado nos testes de down de 000005).

- ADR-0005: identificador `code` em inglês; o conteúdo (siglas) é dado de domínio.
