## 2. Objetivo da Task
Implementar o módulo `nationalteam` completo (repository → service → handler → fx.Module) como o **módulo de referência arquitetural** read-only do projeto. Expõe `ListNationalTeams` (público) e `GetNationalTeamByID` (consumido pelo AuthService para validar a seleção no cadastro).

---

## 3. Descrição Detalhada

Conforme §3.2, §4.1, §5.2 e §17 (US-06) do Tech Spec:

- **`internal/nationalteam/repository/national_team_repository.go`**: `NationalTeamRepository` concreto (sqlc) com `ListNationalTeams` e `GetNationalTeamByID` (delegando às queries de `selecoes.sql` — T5). Mapeia `selecoes` (pt-BR) → `NationalTeam` (inglês). Satisfaz a interface declarada pelo AuthService (T7) para o bind em T12.
- **`internal/nationalteam/service/national_team_service.go`**: `NationalTeamService` read-only que delega ao repository (`ListNationalTeams`, `GetNationalTeamByID`). Sem regra de negócio além de orquestração simples.
- **`internal/nationalteam/handler/national_team_handler.go`**: implementa `NationalTeamServiceServer.ListNationalTeams` → mapeia domínio → `ListNationalTeamsResponse{national_teams}`. RPC **público** (sem auth).
- **`internal/nationalteam/module.go`**: `fx.Module("nationalteam", ...)` que provê repository, service e handler. O repository é exportado para o composition root bindar à interface `NationalTeamRepository` do AuthService.

Este módulo é o template canônico de camadas + fx.Module para figurinhas/trocas futuras (US-06).
