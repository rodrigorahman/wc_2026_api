## 2. Objetivo da Task
Implementar o `UserRepository` concreto que satisfaz a interface declarada pelo `AuthService` (T7), delegando às queries tipadas geradas por sqlc (`CreateUser`, `GetUserByEmail`). Valida em integração as garantias finais do banco: UNIQUE de e-mail e FK de `selecao_id`.

---

## 3. Descrição Detalhada

Conforme §3.2, §7.2 e §7.4 do Tech Spec:

- **`internal/auth/repository/user_repository.go`**: tipo concreto `UserRepository` que recebe `*sqlc.Queries` (ou `*sql.DB`) e implementa:
  - `CreateUser(ctx, user)` — insere em `usuarios` (mapeando campos Go inglês → colunas pt-BR via sqlc).
  - `GetUserByEmail(ctx, email)` — busca por e-mail; retorna not-found tratável quando ausente.
  - Mapear domínio (`User` em inglês) ↔ structs sqlc. Retornar erro sentinela de not-found consumível pelo service.
- O repositório é thin wrapper sobre sqlc (queries parametrizadas — SQL injection impossível por design, §11.4). O bind concreto→interface ocorre no `fx.Module` auth (T11).

Não declarar interface aqui (placement é no consumidor — T7).
