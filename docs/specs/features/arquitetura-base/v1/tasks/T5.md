## 2. Objetivo da Task
Entregar a fundação de persistência: abrir conexão SQLite com driver pure-Go `modernc.org/sqlite` (PRAGMAs corretos), aplicar migrations versionadas (golang-migrate) no boot, definir as queries sqlc e gerar o código tipado, e prover tudo via `fx.Module`. Inclui o helper de teste `TestNewDB`, reutilizado pelas tasks de integração subsequentes.

---

## 3. Descrição Detalhada

Conforme §7 (Persistência), §3.2 e ADR-0001 do Tech Spec:

- **`internal/db/db.go`**: abrir `*sql.DB` via driver `sqlite` (modernc) aplicando na conexão:
  - `PRAGMA foreign_keys = ON` (enforcement da FK `selecao_id` — sem isto CT-019 passa falsamente).
  - `PRAGMA journal_mode = WAL`.
  - `PRAGMA busy_timeout = 5000`.
  - `db.SetMaxOpenConns(1)` (alinha ao single-writer do SQLite — §7.4).
  - Aplicar migrations via golang-migrate driver **`sqlite`** (NUNCA `sqlite3`/CGO — ADR-0001) com `migrate.WithInstance` sobre o **mesmo `*sql.DB`** aberto (§7.3). Migrations embarcadas via `embed.FS`.
- **`internal/db/migrations/`** (up+down):
  - `000001_create_selecoes` — tabela `selecoes` (`id` TEXT PK, `nome` TEXT NOT NULL UNIQUE).
  - `000002_seed_selecoes` — popula a lista fixa de seleções da Copa (seed; down = delete).
  - `000003_create_usuarios` — tabela `usuarios` (`id` TEXT PK, `nome_completo` TEXT NOT NULL, `email` TEXT NOT NULL UNIQUE, `senha_hash` TEXT NOT NULL, `selecao_id` TEXT NOT NULL FK→`selecoes(id)`, `criado_em` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP) + índice em `selecao_id`.
- **`internal/db/queries/`**: `selecoes.sql` (`ListNationalTeams`, `GetNationalTeamByID`) e `usuarios.sql` (`CreateUser`, `GetUserByEmail`) — nomes de query em inglês; colunas pt-BR.
- **`internal/db/sqlc/`**: código gerado por `make sqlc` (struct `User`/`NationalTeam`, `Queries`) com a ponte de idioma do `sqlc.yaml` (T1).
- **`internal/db/module.go`**: `fx.Module("db", ...)` que provê `*sql.DB`/`*sqlc.Queries`, aplica migrations no `OnStart` e fecha a conexão no `OnStop` (§10.2).
- **`internal/testutil/db.go`**: `TestNewDB(t)` — abre SQLite in-memory (modernc), aplica migrations, habilita `foreign_keys=ON`, registra `t.Cleanup`. Reutilizado por T8/T9/T11/T12.

Identificadores do banco em pt-BR; mapeamento para Go em inglês via sqlc (§3.2/§7.2).

## 6. Testes

#### Integração: Conexão DB + Migrations (`internal/db/db_test.go`)

Setup: SQLite in-memory (modernc) via `TestNewDB`/`sql.Open`; migrations reais aplicadas (boundary: db).

| CT | Teste | CA | Objetivo | Fluxo | Validação |
|----|-------|----|----------|-------|-----------|
| CT-F06 | TestOpenDB_ForeignKeysEnabled | CA-09 | Verificar que toda conexão aberta tem foreign_keys=ON (senão CT-019 falha silenciosa) | OpenDB + migrate | `PRAGMA foreign_keys` retorna 1 |
| CT-F07 | TestOpenDB_JournalModeWAL | CA-09 | Verificar journal_mode=WAL (concorrência de leitura) | OpenDB em arquivo `t.TempDir()` | `PRAGMA journal_mode` == "wal" |
| CT-F08 | TestOpenDB_TablesExist | CA-09 | Verificar que migrations criam `usuarios` e `selecoes` | OpenDB + migrate | ambas tabelas presentes em sqlite_master |
| CT-F09 | TestOpenDB_SeedApplied | CA-10 | Verificar que migration 000002 populou seleções (seed não vazio) | OpenDB + migrate | `COUNT(*) FROM selecoes` > 0 |
| CT-021 | TestQuery_NoMigrations_Error | CA-10 | Verificar que consultar `selecoes` sem migrar falha explicitamente (não retorna vazio silencioso) | abrir DB direto sem migrate; consultar | err != nil, "no such table" |

> Recomendação QA: consolidar CT-F06/F07/F08/F09 como sub-testes de `TestOpenDB_PostMigrateState` reutilizando `TestNewDB`. WAL exige arquivo real (`t.TempDir()`), não `:memory:`. CT-021 (= CT-F10 do contexto QA) cobre o caso negativo na camada de db.
