## 2. Objetivo da Task
Definir o contrato gRPC da aplicação em arquivos `.proto` versionados (`wc2026.<dominio>.v1`) com validação declarativa via `buf.validate` (protovalidate) e gerar os stubs Go em `internal/pb`. Este é o artefato de contrato consumido por handlers e interceptors.

---

## 3. Descrição Detalhada

Conforme §4 (Contratos), §15 (Versionamento) e §6.1 (Validações) do Tech Spec:

- **`proto/wc2026/auth/v1/auth.proto`** — `AuthService` com:
  - `Register(RegisterRequest) returns (RegisterResponse)` — `RegisterRequest`: `full_name` (string, required, min_len), `email` (string, required, formato email), `password` (string, required, min_len 8), `national_team_id` (string, required, uuid). `RegisterResponse`: `user_id` (string).
  - `Login(LoginRequest) returns (LoginResponse)` — `LoginRequest`: `email` (required, email), `password` (required). `LoginResponse`: `access_token` (string), `expires_at` (`google.protobuf.Timestamp`).
  - `GetMe(GetMeRequest) returns (GetMeResponse)` — RPC protegido de referência (§4.1). `GetMeResponse`: `user_id`, `full_name`, `email`, `national_team_id`.
  - Regras de validação declaradas via opções `buf.validate.*` (required, email, min_len 8, uuid) — §6.1.
- **`proto/wc2026/nationalteam/v1/national_team.proto`** — `NationalTeamService` com `ListNationalTeams(ListNationalTeamsRequest) returns (ListNationalTeamsResponse)`. `ListNationalTeamsRequest` vazio; `ListNationalTeamsResponse`: `repeated NationalTeam national_teams`; `NationalTeam`: `id` (string), `name` (string).
- **Geração**: `make proto` (buf generate) produzindo `internal/pb/wc2026/...` (`*.pb.go`, `*_grpc.pb.go`). Stubs em `internal/` pois só este módulo os consome na v1 (§3.2).

Campos proto em inglês (`national_team_id`); o mapeamento para a coluna `selecao_id` ocorre na camada repository/sqlc (§4.2), não aqui.
