## 2. Objetivo da Task
Estabelecer a base de tooling e build do projeto Go: declarar todas as dependências em `go.mod`, configurar geração de stubs proto (buf), geração de queries tipadas (sqlc), alvos de build cross-platform (`Makefile`) e o template de variáveis de ambiente (`.env.example`). Nenhum código de domínio — apenas a fundação reprodutível de build.

---

## 3. Descrição Detalhada

Criar a infraestrutura de build conforme §18 (Dependências) e §16.2 (Empacotamento) do Tech Spec:

- **`go.mod`**: adicionar as dependências da stack (§18): `google.golang.org/grpc`, `go.uber.org/fx`, `modernc.org/sqlite`, `github.com/golang-migrate/migrate/v4`, `github.com/bufbuild/protovalidate-go`, `github.com/grpc-ecosystem/go-grpc-middleware/v2`, `github.com/golang-jwt/jwt/v5`, `golang.org/x/crypto`, `github.com/spf13/viper`, `go.uber.org/zap`, `github.com/stretchr/testify`, `github.com/google/uuid`, mais `google.golang.org/protobuf`. Manter `go 1.26.1` e o module path existente (`github.com/rodrigorahman/wc_2026_api`).
- **`buf.yaml`** + **`buf.gen.yaml`**: configurar geração com `protoc-gen-go` e `protoc-gen-go-grpc`, com `out: internal/pb` (stubs internos — §3.2). Lint/breaking opcional.
- **`sqlc.yaml`**: engine `sqlite`, schema apontando para `internal/db/migrations`, queries em `internal/db/queries`, output em `internal/db/sqlc`. Configurar `rename`/`overrides` para a ponte pt-BR→inglês (§3.2, §7.2): ex. `nome_completo`→`FullName`, `senha_hash`→`PasswordHash`, `selecao_id`→`NationalTeamID`, `criado_em`→`CreatedAt`; structs `usuarios`→`User`, `selecoes`→`NationalTeam`.
- **`Makefile`**: alvos `proto` (buf generate), `sqlc` (sqlc generate), `test` (`go test ./...`), `build` e **`build-all`** — cross-compile com `CGO_ENABLED=0` para `linux/amd64`, `linux/arm64`, `darwin/arm64`, `windows/amd64` (ADR-0001; alvo da verificação CT-033 em T12).
- **`.env.example`**: documentar `DB_PATH`, `JWT_SECRET`, `JWT_TTL`, `GRPC_PORT` (§11.6). NÃO incluir segredo real.

Decisões já tomadas: driver `modernc.org/sqlite` (pure-Go, ADR-0001); o `sqlc.yaml` é o ponto único da ponte de idioma (§21 — candidato a ADR).
