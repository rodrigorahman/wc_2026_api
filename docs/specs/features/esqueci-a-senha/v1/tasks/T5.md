## 2. Objetivo da Task
Introduzir no `AuthService` a base da recuperação de acesso: os campos temp no `service.User`, a interface `EmailSender` (declarada no consumidor), o boundary `genTempPassword` (default `crypto/rand`), os métodos novos da interface `UserRepository`, e o fluxo `RequestPasswordRecovery` (resposta imediata genérica + dispatch assíncrono) com seu núcleo síncrono testável `processRecovery`.

---

## 3. Descrição Detalhada

### Struct e interfaces (em `auth_service.go`)
- `service.User`: adicionar `TempPasswordHash string` e `TempPasswordExpiresAt time.Time` (zero-value quando NULL).
- Nova interface `EmailSender` (consumidor): `Send(ctx context.Context, to, subject, body string) error`. **Assinatura canônica** — T3 (concretos) e T9 (bind) devem espelhá-la.
- Interface `UserRepository`: adicionar
  - `SetTempPassword(ctx context.Context, id string, hash string, expiresAt time.Time) error`
  - `UpdatePassword(ctx context.Context, id string, hash string) error`
- Boundary `genTempPassword`: tipo `func() (string, error)`, injetado no construtor (default usa `crypto/rand`), espelhando o padrão de `compareHash`/`clock`. Default gera senha forte aleatória (alfabeto seguro, comprimento adequado).

### Construtor
- `NewAuthService` ganha o parâmetro `emailSender EmailSender`. O `genTempPassword` default é atribuído internamente (como `compareHash`); abrir seam para teste via `export_test.go`.
- Constante `recoveryTTL = 15 * time.Minute`.

### `RequestPasswordRecovery(ctx, email string) (string, error)`
- Dispara `go s.processRecovery(context.WithoutCancel(ctx), email)` e retorna **imediatamente** a mensagem genérica pt-BR (constante, ex.: `"Se o e-mail estiver cadastrado, enviaremos as instruções de recuperação."`), sempre `OK`.

### `processRecovery(ctx, email string) error` (síncrono, testável)
1. `GetUserByEmail`. Se `errors.Is(err, ErrUserNotFound)` → retorna `nil` (silêncio total, CA-02). Outro erro → log + retorna nil (best-effort; não há resposta a alterar).
2. `genTempPassword()` → senha plana.
3. `bcrypt.GenerateFromPassword(plain, s.bcryptCost)` → hash.
4. `SetTempPassword(id, string(hash), s.clk.Now().Add(recoveryTTL))`.
5. `EmailSender.Send(ctx, email, assunto, corpo)` — corpo pt-BR em texto simples com a senha temporária, validade (15 min) e instrução de troca. Falha de `Send` → log `warn`/`error` com `to`/`subject`/`err` (**nunca** a senha/body) e retorna nil (RN4/CA-03).

> **Fora de escopo**: `Login` 2º branch (T6), `ChangePassword` (T7), handler (T8), bind do `EmailSender` real (T9). Aqui só a base + o fluxo de pedido.

## 7. Notas / Observações
- `context.WithoutCancel(ctx)` é o que impede a goroutine de morrer quando o RPC retorna (§10.2). O teste do fluxo assíncrono é indireto; o núcleo testável é `processRecovery` (síncrono).
- Mock-driven confidence proibido: o hash gravado é verificado com `bcrypt.CompareHashAndPassword`, não pelo valor que o mock plantou.
- A interface `EmailSender` é declarada AQUI (consumidor); o concreto (T3) não conhece este pacote. O bind acontece em T9.
- `genTempPassword` segue o padrão de seam de `compareHash` (produção usa o real; teste injeta conhecido).
