## 2. Objetivo da Task
Criar a capacidade de envio de e-mail transacional (ADR-0006) como infra reusável em `internal/infra/email`: `ResendSender` (SDK `resend-go`, pure-Go) e `NoopSender` (dev — loga apenas `to`/`subject`, nunca o body), ambos satisfazendo a assinatura canônica `Send(ctx, to, subject, body string) error` da interface `EmailSender` declarada no consumidor (`auth/service`, T5).

---

## 3. Descrição Detalhada

### `internal/infra/email/noop.go`
- `NoopSender` com `*zap.Logger`. `NewNoopSender(logger *zap.Logger) *NoopSender`.
- `Send(ctx, to, subject, body string) error`: loga em nível **info** apenas `to` e `subject` (zap fields); **nunca** o `body` (contém a senha temporária — RN7/CA-09). Retorna `nil`.

### `internal/infra/email/resend.go`
- `ResendSender` via SDK `github.com/resend/resend-go` (pure-Go — ADR-0001). `NewResendSender(apiKey, fromEmail string, logger *zap.Logger) *ResendSender`.
- Para testabilidade sem HTTP real, declarar **interface mínima local** sobre o client do SDK (ex.: `resendClient` com o método de envio) e injetar — o construtor de produção embrulha o client real do SDK num adapter. Padrão "interface no consumidor mais próximo".
- `Send(ctx, to, subject, body string) error`: monta o request com `From = fromEmail`, `To = [to]`, `Subject = subject`, corpo em texto simples = `body`; chama o client; **propaga** o erro do SDK (o caller — service — trata best-effort). Não engole erro, não embrulha de forma a perder `errors.Is`.

### `go.mod`
- Adicionar `github.com/resend/resend-go` (confirmar pure-Go; `make build-all` deve permanecer verde — ADR-0001).

> **Fora de escopo**: a interface `EmailSender` (declarada em T5) e o bind por config (T9). Aqui só os concretos + dependência.

- **Cenários não cobertos** (do QA): carga/concorrência do `Send` (NoopSender é stateless); log de falha do best-effort no nível do service (responsabilidade do caller, coberto pelos CTs do service T5/T7).

- O log de **falha de envio** (warn com `to`/`subject`/`err`) é do caller (service) — o `ResendSender` apenas propaga o erro.
